# 文件名映射设置说明

打开「设置 → 映射」。每一行规则把一个检验表或 Droplist 文件名转换为用于合并的类型。
保存后写入程序同级 `data/filename_mappings.json`，不需要手动编辑 JSON。

| 界面字段 | 用途 | 示例 |
| --- | --- | --- |
| 文件名关键字 | 在文件名中寻找的文字 | `MPO国外DSV自提` |
| 检验表类型 | 输出明细的详细类型，不会改写源表原备注 | `DSV自提` |
| 归总类别 | 核对数量时归入 `光联` 或 `MPO` | `MPO` |
| 备注 | 输出中的映射说明，可留空 | `陆运` |
| 匹配方式 | `包含`、`完全` 或 `正则` | `包含` |

## 常用例子

| 文件名示例 | 建议关键字 | 详细类型 | 归总类别 |
| --- | --- | --- | --- |
| `9.19MPO国外DSV自提资料.XLSX` | `MPO国外DSV自提` | `DSV自提` | `MPO` |
| `9.19MPO国外FED-EX国内自提资料.XLSX` | `MPO国外FED-EX` | `FedEx自提` | `MPO` |
| `9.19国外Expeditors自提资料.XLSX` | `国外Expeditors` | `Expeditors自提` | `光联` |
| `9.17国外第3车出货资料..XLSX` | `国外第3车` | `第三车` | `光联` |
| `Drop shipment list9.17 - SAPMPO.xlsx` | `MPO` | `MPO` | `MPO` |
| `Drop shipment list9.17- SAP光联.xlsx` | `光联` | `光联` | `光联` |

`国外第…车`未命中规则时，程序默认归入光联。若想保留“第三车”等详细类型，
请仍然添加该文件名规则。Droplist 只应归入光联或 MPO；如果文件名和父文件夹
都没有类别，程序会标为“未识别”，不要靠猜测自动归类。

## 匹配顺序

1. `完全`：去掉扩展名后，整个文件名相同。
2. `正则`：高级用法，例如 `国外第[0-9]+车`。
3. `包含`：推荐；文件名含关键字即可。多个包含规则都命中时，关键字更长者优先。

因此，具体规则 `MPO国外DSV自提` 会优先于通用规则 `MPO`。在页面下方输入
示例文件名即可预览最终详细类型、归总类别和命中的规则。保存前建议用真实
文件名各测一例。异常文件页会列出未识别、列宽不同、空表等情况。

## 数量核对与缺失文件

检验表和 Droplist 按「日期 + 光联/MPO」分别求和，再比较数量。源文件缺失、
文件名无法识别、被跳过的空表都不会被程序补造。如果一侧显示“缺少数据”，
先检查输入文件夹是否齐全，再检查文件名映射；这两种问题都需要人工确认。

源检验表的格式和详细类型会保留在合并明细页。不同源表列数不同时，程序按
最大列数保留原始列，并把新增的映射字段放在原始列之后。
