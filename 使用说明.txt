# ShipmentTrack v1.1

快递批量查询工具（DHL / DSV / EI / UPS / FedEx），Garlicgoose 制作。

## 功能

- 读取 Excel（第一列=快递公司，第二列=运单号），批量查询运单状态
- 每个快递（DHL/DSV/EI/UPS）执行前自动预热：打开官网、关闭 cookie/欢迎弹窗等浮层，再开始查询
- DHL / DSV / EI / UPS 通过外接浏览器查询；FedEx 状态通过官方 API 查询，
  送达后用系统真实 Microsoft Edge 保存官网查询页面
- 已送达货件自动下载 POD（PDF）到 `输出文件夹\pdf\对应快递`
- 输出结果 Excel：运单号 / 快递公司 / **状态** / 抵达时间 / 用时(秒) / 备注
  - 「状态」列是读取到的原始状态（如 Delivered / In Transit），用于排查问题
  - FedEx 返回 2–39 个关联单时：全部送达才算送达
  - FedEx 返回达到 40 个关联单时：当前 40 个全部送达则暂定送达，
    备注列标注需要人工复核
  - FedEx 不下载官方 POD：保存 `运单号.pdf` 查询主页和
    `运单号+.pdf` 详情页两份文件
- 勾选「只查状态」时只查状态，不下载任何 PDF
- 检验表与 Droplist 可以一起处理，也可以任选一侧单独合并；只生成已选侧文件
- 合并检验表.xlsx 的“类型箱数”页按日期汇总各原类型箱数
- 检验表保留澳车、港车、814S 等详细类型，仅在核对时归总到光联/MPO
- FedEx 随机抽取 20% 运单，查询主页和详情页两份都检查；其他承运商随机
  抽取 5%，结果保存为 pod_audit.xlsx
  - FedEx 检查运单号与英文官网“Signed for by”字段
  - 其他承运商检查运单号与 PDF 中的送达状态字段

## 使用方法

1. 双击 `Shipment Track.exe` 启动（首次启动会自动检查授权，通过后进入主界面）
2. 打开「设置」：
   - 输入 Excel（快递公司+运单号两列）
   - 输出文件夹
   - EI 邮箱 / 密码（EI 运单需要）
   - FedEx API Key / Secret（developer.fedex.com 注册获取）
   - FedEx 网页 POD 使用 Windows 自带的真实 Edge；首次启动会预热 30 秒，
     如果公司要求登录 Edge 账号，请在这段时间内完成登录
   - 实际浏览器：选择 Microsoft Edge 或 Google Chrome，然后自动检测或
     手动选择对应的 msedge.exe / chrome.exe
   - 勾选「最小化」：浏览器弹出后自动最小化（后台运行，不挡视线）
   - 文件名映射：添加文件名关键字、检验表类型、归总类别和备注，保存后
     自动写入 data\filename_mappings.json；归总类别只能填写光联或 MPO
   - 送达状态：可为 DHL、EI、DSV 添加额外完整状态字段。DHL 仅使用当前
     状态区域，清理空格和末尾标点后仍要求完整匹配
3. 在「跟踪」页面选择输入 Excel 和输出文件夹，点击「开始查询」
4. 在「Excel 合并与核对」页面选择检验表、Droplist 中至少一个文件夹和
   输出文件夹，点击「开始合并与核对」
5. POD 绿色圆点及各项“打开”按钮可以直接打开已生成文件

跟踪和 Excel 合并可以同时运行。Droplist 明细页按第 3 行的 S/O、QTY 表头
识别；不要求页签名包含类型或日期。首个汇总页、Address、Sheet1 和空表不计数。

## 目录说明

```
Shipment Track\
├── Shipment Track.exe    主程序
├── data\                 设置、映射、缓存和机器标识
│   ├── filename_mappings.json
│   └── delivery_status_mappings.json
└── 使用说明.txt          本文件
```

程序使用电脑已安装的 Edge 或 Google Chrome，不需要另行下载 Chromium。
头像弹窗中可以查看 v1.1 更新日志或手动检查 GitHub 新版本。

## 授权说明（给使用者）

- 程序启动时验证 GitHub 上经过数字签名的共享开关文件
- 联网关闭后，下次启动无法使用；断网缓存最多保留 24 小时
- 需要开通时，把 `data\machine_id` 中的机器码发给管理员
- 管理员修改并重新签名共享文件，使用者不需要安装或保存授权文件

## 常见问题

- **启动报 "Unable to start"**：网络不可用或未授权，检查网络/联系管理员
- **FedEx 查询报错**：先在设置页点击“验证 FedEx API”，再确认 Windows
  自带 Edge 可以正常访问 fedex.com
- **浏览器没弹出来**：设置了「最小化」，任务栏能看到；取消勾选设置中的
  「最小化」即可正常显示
- **POD 出现 Cookie 或聊天框**：程序会在主页和详情页打印前分别关闭或隐藏，
  不应遮挡运输记录
- **同事电脑没有 Python / 库**：不需要，exe 已内置程序运行库；电脑只需
  安装 Edge（Windows 默认具备）或 Google Chrome
